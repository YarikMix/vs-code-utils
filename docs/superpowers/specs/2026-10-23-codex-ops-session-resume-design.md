# Codex Ops: запуск сессии в текущем окне

## Цель

Агент, работающий во встроенном терминале WSL, запускает произвольную найденную сессию Codex в новой вкладке редактора того же окна VS Code. Существующая Smart Paste остается доступной. Статусы терминалов и изменения Codex CLI отложены.

## Интерфейс

После активации расширение добавляет в новые терминалы `CODEX_OPS_ENDPOINT` и `CODEX_OPS_HELPER`. Агент вызывает `powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File "$CODEX_OPS_HELPER" -Endpoint "$CODEX_OPS_ENDPOINT" -SessionId <UUID>`. Скрипт отправляет локальный POST, получает подтверждение и выходит с ненулевым кодом при ошибке.

## Архитектура

Расширение запускается в UI extension host Windows. Каждый экземпляр окна слушает случайный порт только на `127.0.0.1` и использует случайный токен. URL и путь Windows PowerShell-скрипта добавляются в окружение новых терминалов данного окна через `environmentVariableCollection`, без сохранения между перезапусками. Только `POST /<token>/<UUID>` допускается; UUID проверяется строго. Обработчик создаёт `TerminalLocation.Editor`, показывает терминал и отправляет `codex resume <UUID>`.

Идентификатор расширения становится `local.codex-ops`; старый `local.codex-smart-paste` пользователь может удалить. Smart Paste получает команду `local.codexOps.paste` и прежние сочетания клавиш.

## Границы и проверка

Новые переменные окружения видны только терминалам, запущенным после активации расширения. Проверяются отказы при плохом методе, токене и UUID, запуск терминала при корректном запросе, манифест, типы, сборка и упаковка. Реальная работа Windows UI/WSL и раскладок проверяется вручную после установки VSIX.
