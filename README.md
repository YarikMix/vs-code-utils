# Codex Smart Paste

Локальное расширение Windows VS Code для Codex во встроенном терминале, включая терминалы WSL. Проверка формата Windows-буфера выполняется на Windows в UI extension host (`extensionKind: ui`). Внешние сервисы и зависимости времени выполнения не нужны.

| Сочетание в терминале | Действие |
| --- | --- |
| Ctrl+V / Ctrl+М | Если в буфере есть изображение — отправить Codex Alt+v; иначе — штатная вставка текста VS Code |
| Alt+V / Alt+М | Отправить Codex Alt+v для вставки изображения |
| Ctrl+C / Ctrl+С с выделением | Копировать выделенный текст терминала |
| Ctrl+C без выделения | Сохраняется штатное прерывание |
| Ctrl+Enter, Shift+Enter | Отправить `ESC[13;2u` для переноса строки в Codex, без отправки промпта |
| Ctrl+Shift+V | Сохраняется штатная вставка текста VS Code |

V и C заданы физическими клавишами, поэтому сочетания работают в английской и русской раскладках. Все пять привязок расширения ограничены фокусом терминала. Расширение не проверяет, запущен ли Codex: команды вставки изображения предназначены для терминала с Codex.

Расширение добавляет `local.codexSmartPaste.paste` в значение по умолчанию `terminal.integrated.commandsToSkipShell`, чтобы терминал передавал Ctrl+V команде VS Code. Встроенные исключения VS Code сохраняются. Если вы задаёте собственный массив этой настройки в пользовательских настройках или настройках рабочей области, включите в него `local.codexSmartPaste.paste`. Настройка `terminal.integrated.sendKeybindingsToShell: true` имеет приоритет над этим списком и может передавать сочетание оболочке; для работы Smart Paste оставьте её выключенной.

Изображение имеет приоритет, если буфер содержит и изображение, и текст. PowerShell в STA-режиме возвращает только `true`/`false`; содержимое буфера не сохраняется, не логируется и не меняется. При ошибке или таймауте 3 секунды показывается сообщение без автоматической вставки. Повторное нажатие во время проверки игнорируется; смена активного терминала отменяет вставку. Буфер может измениться между проверкой и вставкой.

## Установка

Из корня репозитория:

```sh
node --test
node --check extension.js
node --check src/smart-paste.js
npx --yes @vscode/vsce package --no-dependencies --allow-missing-repository --skip-license
```

Установите `codex-smart-paste-0.1.0.vsix` через **Extensions: Install from VSIX...** в локальный Windows VS Code. При установке из CLI используйте Windows `code.cmd --install-extension <Windows-путь-к-VSIX>`, даже если исходники находятся в WSL. Идентификатор: `local.codex-smart-paste`.

До удаления пользовательских привязок сохраните копию `%APPDATA%\Code\User\keybindings.json`. После подтверждения локальной установки удалите только пять записей, перенесённых в манифест расширения: Ctrl+[KeyV], Alt+[KeyV], Ctrl+[KeyC], Ctrl+Enter и Shift+Enter с указанными выше условиями терминала. Другие пользовательские привязки сохраните.

Выполните **Developer: Reload Window**. Проверьте в Codex текст и скриншот через Ctrl+V в английской и русской раскладках, Alt+V, Ctrl+C с выделением и без, Ctrl+Enter и Shift+Enter. Последние два сочетания должны переносить строку без отправки промпта. Автоматические тесты не заменяют эту проверку клавиатуры.

## Откат

Удалите **Codex Smart Paste** в локальном Windows VS Code (или `code.cmd --uninstall-extension local.codex-smart-paste`). Восстановите сохранённые пять записей из резервной копии `keybindings.json`; если после установки появились другие изменения, объедините записи, сохранив эти изменения. Для обычной вставки Ctrl+V должна снова указывать на `workbench.action.terminal.paste` при `terminalFocus`. Выполните **Developer: Reload Window**.

Храните резервную копию рядом с Windows `keybindings.json`.
